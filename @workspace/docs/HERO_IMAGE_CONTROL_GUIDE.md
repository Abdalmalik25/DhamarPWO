## تم إضافة حقول الصور التحكمية للبطل والمحتوى التوعوي

### ما تم تنفيذه:

#### 1. تعديل سكيما Sanity (`studio/schemaTypes/siteSettings.ts`):
- تم إضافة حقل `heroImage` - الصورة التعريفية للبطل الرئيسي
- تم إضافة حقل `heroBackgroundImage` - الخلفية الجغرافية للبطل (خريطة محافظة ذمار)
- تم إضافة حقل `parkingGuidelines` - إرشادات تنظيم المواقف وبنية التحتية
- تم إضافة حقل `governorateMap` - خريطة المحافظة الكاملة

#### 2. تعديل استعلامات Sanity (`src/lib/sanity.ts`):
- تم تحديث استعلام `SITE_SETTINGS` لجلب جميع الصور الجديدة

#### 3. تعديل HeroSection (`src/pages/home/sections/HeroSection.tsx`):
- الصور الآن تجلب من Sanity تلقائيًا
- الخلفية الجغرافية تُظهر خريطة المحافظة كخلفية مؤسسية حضورية
- عند عدم وجود صور، يتم العودة للصور الافتراضية

#### 4. إضافة زر الإعدادات (`src/components/Header.tsx`):
- زر "الإعدادات" يظهر على الصفحة الرئيسية فقط
- يفتح لوحة تحكم Sanity مباشرة

#### 5. إضافة دالة urlFor (`src/lib/sanity/client.ts`):
- لتحويل مراجع الصور من Sanity إلى روابط قابلة للاستخدام

### كيفية الاستخدام:

1. **افتح لوحة تحكم Sanity**: https://xqbc1jjs.sanity.studio
2. **انتقل إلى قسم "إعدادات الموقع"** (Site Settings)
3. **ارفع الصور حسب الفئات**:
   - **صورة البطل الرئيسية**: الشعار أو الصورة التعريفية (داخل الإطار الدائري)
   - **خلفية البطل الجغرافية**: خريطة محافظة ذمار أو خلفية توعوية
   - **إرشادات تنظيم المواقف**: الصور التوعوية لتنظيم المواقف
   - **خريطة المحافظة**: الخريطة الكاملة للمحافظة

4. **احفظ التغييرات** - سيتم تحديث العرض تلقائيًا

### الصور الافتراضية المتوفرة:
- **الشارع النموذجي (البطل)**: `/images/imagemainstreet.png`
- **خلفية الخريطة الجغرافية**: `/images/ThamarMapMain.png`
- **إرشادات تنظيم المواقف**: `/images/Parking_Guide_Brochure1.png`

### ملاحظات تقنية:
- الحجم الموصى به للبطل: 512x512 بكسل أو أكبر (شكل دائري)
- الصيغ المدعومة: JPG, PNG, SVG
- يمكن ضبط مناطق التركيز (Hotspot) لتعديل التصTrim التلقائي
